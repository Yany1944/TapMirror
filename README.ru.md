<h1 align="center">TapMirror</h1>

<p align="center">Одно касание в шторке Android — и экран телефона открывается на ПК с Windows.<br>
Малая задержка, управление мышью и клавиатурой, по Wi-Fi, без консоли. Работает на <a href="https://github.com/Genymobile/scrcpy">scrcpy</a>.</p>

## Что умеет

- **Плитка «Экран на ПК»** в шторке: нажали — трансляция пошла, нажали ещё раз — остановилась. Уведомление показывает статус и кнопку «Стоп».
- **Качество scrcpy**: видео в реальном времени, управление мышью и клавиатурой, звук телефона на ПК.
- **По Wi-Fi из любой комнаты**, без кабеля и команд.
- **Отладка включена только во время трансляции.** Телефон включает adb на сеанс и выключает после. Это важно для банковских и госприложений, которые не работают при включённой отладке.
- **С root и без.** С root всё работает сразу. Без root нужно один раз выдать разрешение с ПК.
- **Лёгкая программа на ПК**: значок в трее, в ожидании не тратит процессор, запускается с Windows, сама скачивает scrcpy.
- **Новые телефоны** в первый раз нужно разрешить на ПК.
- **Настройки на телефоне**: разрешение, битрейт, частота кадров, кодек, звук, гасить экран телефона, не давать засыпать.
- Английский и русский языки.

## Как работает

1. Плитка рассылает по сети UDP-сообщение (порт 27199), программа на ПК отвечает.
2. Телефон включает adb только на этот сеанс: с root — adb по TCP на порту 5555, без root — «Отладку по Wi-Fi».
3. ПК в первый раз спрашивает, разрешить ли телефон, затем подключается через adb и запускает scrcpy.
4. Пока идёт трансляция, телефон раз в 3 секунды проверяет, что ПК на связи.
5. Окно закрыли, плитку нажали, ПК уснул или пропал Wi-Fi — телефон за несколько секунд выключает отладку.

Подробности: [docs/protocol.md](docs/protocol.md).

## Что нужно

- Android 11 или новее.
- Windows 10 или 11, 64 бита (используется встроенный .NET Framework 4.8).
- Телефон и ПК в одной сети и видят друг друга (не гостевая сеть, без «изоляции клиентов»).
- Root (Magisk, KernelSU, APatch) или один раз ПК с adb, чтобы выдать разрешение без root.

Проверено на Pixel 7 Pro (Android 17 beta, Magisk) с Windows 11, в режимах с root и без.

## Установка

### 1. ПК

1. Скачайте **TapMirror.exe** в [Releases](https://github.com/Yany1944/TapMirror/releases/latest), положите в отдельную папку (например `Документы\TapMirror`) и запустите.
2. При первом запуске он предложит:
   - скачать свежий официальный **scrcpy** с GitHub (проверяет SHA-256);
   - добавить правило **брандмауэра Windows** для UDP-порта 27199 (попросит права администратора).

   Согласитесь на оба. Дальше TapMirror живёт в трее и запускается вместе с Windows.

### 2. Телефон

1. Скачайте **TapMirror.apk** в [Releases](https://github.com/Yany1944/TapMirror/releases/latest) и установите.
2. Откройте приложение. Первый экран — пошаговый список настройки:
   1. TapMirror на ПК;
   2. поиск ПК (кнопка «Искать»);
   3. доступ к отладке: **с root** нажмите «Проверить root» и разрешите. **Без root** — см. ниже;
   4. параметры разработчика включены;
   5. плитка добавлена в шторку;
   6. уведомления включены или выключены («только плитка»).
3. Нажмите плитку. В первый раз ПК спросит, разрешить ли этот телефон.

### Без root: одно разрешение, один раз

Без root приложение само переключает «Отладку по Wi-Fi». Для этого нужно разрешение `WRITE_SECURE_SETTINGS`, которое может выдать только компьютер. В меню TapMirror в трее выберите **«Set up a phone without root…»** и один из вариантов:

- **USB**: включите отладку по USB, подключите кабель, разрешите на телефоне, нажмите «Grant over USB».
- **Без кабеля**: на телефоне «Для разработчиков» → «Отладка по Wi-Fi» → «Подключить устройство с помощью кода», введите адрес и код в окне, нажмите «Pair and grant».

Или, если вы уже пользуетесь adb:

```
adb shell pm grant io.github.yany1944.tapmirror android.permission.WRITE_SECURE_SETTINGS
```

Потом в каждой сети Wi-Fi один раз откройте «Отладку по Wi-Fi» и разрешите её («Всегда разрешать в этой сети»).

Android не даёт обычным приложениям читать настройки отладки, поэтому без root TapMirror не знает, была ли «Отладка по Wi-Fi» включена раньше. После трансляции он всегда её выключает. Отладку по USB он не трогает (или выключает, если выбрано «Всегда выключать отладку»).

## Настройки

На телефоне (приложение TapMirror → «Трансляция»): разрешение, битрейт (по умолчанию 8 Мбит/с), частота кадров, кодек (H.264), звук на ПК, гасить экран телефона, не давать засыпать, и что делать с отладкой после трансляции: вернуть как было или всегда выключать. В шаге 6 уведомления можно выключить (в настройках системы) и пользоваться только плиткой.

На ПК файл `%APPDATA%\TapMirror\TapMirror.ini` хранит папку scrcpy, путь к adb (необязательно), дополнительные опции scrcpy для всех сеансов (`args=`, например `args=--window-borderless`) и список разрешённых и заблокированных телефонов. Журнал: `%LOCALAPPDATA%\TapMirror\TapMirror.log` (меню → Open log).

## Если не работает

| Проблема | Что делать |
|---|---|
| «ПК не ответил» | TapMirror в трее? Одна сеть? Меню → «Allow through Windows Firewall» (пункт есть, только если брандмауэр может мешать). Гостевая сеть и изоляция клиентов не дают устройствам видеть друг друга. |
| «ПК не ответил» при включённом VPN | VPN, который приложения не могут обойти, пропускает к ПК только по известному адресу. Один раз найдите ПК с выключенным VPN или нажмите «Ввести адрес» в шаге 2 и введите адрес из меню трея («This PC: …»). Дальше всё работает и с VPN. |
| Окно не открывается, ошибка adb | Телефон может спрашивать «Разрешить отладку?» для этого ПК: отметьте «Всегда разрешать». |
| Без root: «Wireless debugging didn't start on the phone» | Один раз откройте «Отладку по Wi-Fi» в этой сети и разрешите («Всегда разрешать в этой сети»). |
| Банковское приложение ругается на отладку | «После трансляции» → «Всегда выключать отладку». |
| Задержка | Уменьшите разрешение или битрейт; Wi-Fi 5 ГГц; ПК по кабелю. |
| AV1 не работает | У большинства телефонов нет кодера AV1; выберите H.264 или H.265. |

## Сборка

- **ПК**: `windows\build.cmd` — компилятор C# встроен в Windows, SDK не нужен. Результат: `windows\bin\TapMirror.exe`.
- **Android**: JDK 17+ и Android SDK (platform 35): `cd android`, затем `gradlew assembleDebug`. Подписанный релиз — через `android\keystore.properties` (см. `android/app/build.gradle.kts`) и `gradlew assembleRelease`.
- `build.cmd` в корне собирает оба в `dist\`.
